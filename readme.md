## How to Use

1. Open any topic folder.
2. Read the code and logic in the `.cpp` files.
3. Compile and run the program locally.

```bash
g++ filename.cpp -o output
./output
```

Example:

```bash
g++ array_example.cpp -o array_example
./array_example
```
